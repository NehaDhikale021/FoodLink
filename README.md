# FoodLink – Smart Food Waste Management System

## Overview

FoodLink is a Java-based food waste management system designed to
connect food donors with NGOs and volunteers to streamline food
donation, request, allocation, and distribution.

## Planned Features

- User registration and authentication
- Food donation management
- Food request management
- Food allocation
- Inventory tracking
- Pickup and delivery status tracking
- Admin management

## Tech Stack

- Java
- JDBC
- MySQL
- SQL
- OOP

## Planned Workflow

Donor → Food Listing → NGO Request → Allocation → Volunteer Pickup → Delivery

## Project Status

🚧 **Under Development**

FoodLink is currently being developed as a moderate-level
Java, JDBC, and MySQL project focused on applying object-oriented
programming and relational database concepts to a real-world
food waste management problem.
